# SimpleCalculator
Java Number Operations Calculator

A simple full-stack Java project that performs arithmetic operations on multiple numbers via:

🌐 Web Interface (HTML + Java backend server)

💻 Console Interface (CLI program)

This project demonstrates core Java fundamentals, HTTP server handling, REST-style APIs, and frontend–backend integration.

🚀 Features
✅ Supported Operations

Sum of numbers

Sequential subtraction

Product of numbers

Average of numbers

✅ Two Ways to Use

Browser-based calculator UI

Terminal/console-based calculator

🏗️ Project Architecture
User (Browser)
    ↓
Frontend (HTML + JS)
    ↓ HTTP Request
Java HTTP Server
    ↓
Calculator Logic
